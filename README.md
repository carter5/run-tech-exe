# RUN TECH.EXE — Event Archive

**Insert Curiosity. Run Possibilities.**

RUN TECH.EXE was a one-day virtual conference held on **October 27, 2026, from 11:00 AM to 5:00 PM Central Time**. The event brought together conversations about technology, innovation, careers, and hiring through two concurrent tracks: **Technology & Innovation** and **Careers & Hiring**.

The event featured **13 talks and 15 speakers**. This repository preserves the original event website as a **static archive** of its program, session descriptions, and speakers.

**View the event archive:** https://carter5.github.io/run-tech-exe/

## Archive status

RUN TECH.EXE has concluded. **The website is no longer accepting registrations, speaker proposals, or volunteer applications.** It remains available as a record of the event rather than an active event-registration page.

The archived site retains its original neon, retro-inspired visual design and includes these updates:

- A notice near the top of the page identifying it as an event archive.
- Registration, speaker, and volunteer Google Forms buttons that remain visible and retain their visual animations, but no longer open forms.
- Removal of the boxes announcing registration and application closing dates.
- Preservation of the event's talks, speaker information, and other historical content.

**Note:** The schedule and event information are historical. The site does not publish private Google Meet links or provide access to past sessions or recordings.

## Website and publishing

This is a static website hosted with **GitHub Pages**.

- `index.html` — Main website, including the page's content, styling, and archive adjustments.
- `run-tech-exe-logo.png` — Standalone logo asset for other uses; the approved website logo is also embedded in the HTML.
- `README.md` — Project and archive documentation.

To publish an update, commit the revised website files to the repository's `main` branch. GitHub Pages serves the site at the URL above when configured to publish from that branch.
